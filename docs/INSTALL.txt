Feedback Flag 0.1.7 · 피드백 플래그
Minecraft Java 26.2 / Fabric

설치
1. Fabric Loader 0.19.5 이상으로 실행하는 Minecraft 26.2 프로필을 준비합니다.
2. mods 폴더에 feedback-flag-0.1.7.jar와 26.2용 Fabric API(0.160.0+26.2 이상)를 넣습니다.
   Fabric API는 별도로 설치해야 합니다. Java 25 이상이 필요합니다.
3. 업데이트할 때는 이전 Feedback Flag JAR를 교체하고 config 폴더를 유지합니다.
서버 설치는 필요하지 않습니다. Mod Menu는 선택 사항입니다.

빠른 시작
• /feedbackflag 또는 /ff → 플래그 꽂기 → 감시할 블록 우클릭
• 이름·색상·태그·메모를 입력하고 저장합니다. 플래그 우클릭으로 다시 수정합니다.
• 메뉴 열기와 플래그 꽂기 단축키는 기본 미지정이며 단축키 설정에서 지정합니다.
• 검색에서 이름·색·태그·활성 상태로 찾고, 여러 항목을 체크해 선택 편집할 수 있습니다.

타임라인
• 첫 변화가 0틱이며 같은 틱의 기록은 펼칠 수 있는 묶음으로 표시됩니다.
• 확대 보기에서 +/− 또는 축 위 휠로 확대하고 구간 위치 슬라이더로 이동합니다.
• 기록 저장은 현재 필터와 확대 구간의 모든 기록을 저장합니다.
  전체를 저장하려면 모든 태그와 전체 구간을 선택합니다.
• 저장 기록에서 게임 안으로 다시 열거나, 저장 폴더의 timeline.html을 브라우저로 엽니다.
• 저장 위치: config/feedback_flag/archives/
  백업·이동할 때는 timeline.json과 timeline.html이 든 폴더 전체를 복사하세요.

표시와 기록 설정
• 표시: 플래그 / 감시 블록 윤곽선 / 둘 다
• 표시 설정: 윤곽선 두께, 플래그 크기·위치, 이름, 가려진 윤곽선, 투명도
• 이 플래그 기록: 해당 플래그 기록 켜기/끄기
• 블록: 종류 변경(돌 → 공기), 상태: 속성 변경(레버 전원 등)

삭제와 보관
• 전체 제거는 확인 후 플래그와 메모를 지우며 기존 타임라인은 남깁니다.
• 되돌리기로 마지막 개별 삭제 또는 전체 제거 한 번을 복원합니다.
• 타임라인 초기화는 기록과 누적 횟수를 지우며 되돌릴 수 없습니다.
  전체 초기화 후 첫 변화부터 다시 0틱입니다. 저장해 둔 기록은 유지됩니다.
• 월드/서버당 128개 플래그와 최근 5,000개 기록을 보관합니다.
• 로딩된 블록의 종류·상태만 기록합니다. 상자 내용물과 관찰하지 못한 동안의 변화는 기록하지 않습니다.
