# Feedback Flag · 피드백 플래그

블록에 개인용 플래그를 꽂아 변화를 기록하고, **첫 변화가 0틱인 타임라인**에서 여러 블록의 작동 순서를 확인하는 Minecraft Java 26.2 / Fabric 모드입니다. 표시는 본인에게만 보이며 서버 설치는 필요하지 않습니다.

## 설치

- Minecraft Java **26.2** / Java **25 이상**
- Fabric Loader **0.19.5 이상**
- Fabric API **0.160.0+26.2 이상인 26.2용 버전** — 별도 설치

`feedback-flag-0.1.7.jar`와 Fabric API를 게임 프로필의 `mods` 폴더에 넣으세요. 업데이트할 때는 이전 Feedback Flag JAR를 교체하고 `config` 폴더는 유지하세요. Mod Menu는 선택 사항입니다.

## 시작하기

1. 월드에서 **`/feedbackflag` 또는 `/ff`**로 메뉴를 엽니다.
2. **플래그 꽂기**를 누르고 감시할 블록을 우클릭합니다.
3. 이름·색상·태그·메모를 입력한 뒤 **저장**합니다.
4. 플래그를 우클릭하면 설정을 다시 엽니다. 빈손으로 웅크린 채 대상 블록을 우클릭해도 됩니다.
5. 타임라인의 틱 묶음을 펼치고 개별 기록을 선택해 변경 전후를 확인합니다.

메뉴 열기와 플래그 꽂기 단축키는 **기본 미지정**입니다. 메뉴의 **단축키 설정**에서 각각 지정할 수 있습니다. 플래그 꽂기 키를 다시 누르면 설치를 취소합니다.

| 명령어 | 기능 |
| --- | --- |
| `/feedbackflag`, `/ff` | 메뉴 열기 |
| `/feedbackflag add` | 바라보는 블록에 플래그 추가 |
| `/feedbackflag place` | 다음 우클릭으로 꽂기 / 설치 취소 |

## 플래그 관리

- **이름·색상·메모:** 이름 최대 32자, 기본 16색 또는 6자리 RGB, 여러 줄 메모 최대 1,024자. 메모는 세부 설정에서 바로 수정합니다.
- **태그:** 쉼표로 구분해 최대 8개, 각각 24자까지 지정합니다. 타임라인에서 태그별로 볼 수 있습니다.
- **검색:** 이름·색상·태그·개별 활성 상태를 함께 검색합니다. 이름과 태그는 일부만 입력해도 됩니다.
- **여러 개 편집:** 검색 결과에서 체크한 뒤 **선택 편집**을 엽니다. 색상·활성 상태·감지 종류·태그를 함께 변경하며, **유지**한 항목과 이름·메모는 그대로 남습니다.
- **삭제 복원:** **되돌리기**로 마지막 개별 삭제 또는 전체 제거 한 번을 복원합니다. 새 삭제가 발생하면 이전 삭제 내역을 대체합니다. 복원 위치가 사용 중이거나 플래그 상한을 넘으면 복원할 수 없습니다.

| 기록 설정 | 기능 |
| --- | --- |
| 전체 기록 | 모든 플래그의 기록을 일시 정지 / 재개 |
| 이 플래그 기록 | 해당 플래그의 기록을 정지 / 재개 |
| 블록 | 블록 종류가 바뀌는 변화 기록. 예: 돌 → 공기 |
| 상태 | 같은 블록의 속성 변화 기록. 예: 레버 전원, 문 열림 |

**이 플래그 기록**이 꺼져 있으면 블록·상태 설정과 관계없이 기록하지 않습니다. 다시 켜도 정지 중의 변화는 채우지 않습니다.

## 타임라인 보기와 저장

같은 틱의 변화는 한 묶음으로 표시합니다. 접힌 묶음에는 플래그 색과 **외 N개**가 표시되며, 펼치면 각 기록의 상세 내용을 볼 수 있습니다.

상단 버튼은 **확대 보기 → 저장 기록 → 타임라인 초기화** 순서입니다.

| 확대 보기 조작 | 기능 |
| --- | --- |
| `+` / `−`, 축 위 마우스 휠 | 확대 / 축소 |
| 구간 위치 슬라이더 | 확대 배율을 유지하며 보는 위치 이동 |
| `<` / `>` | 현재 구간의 절반만큼 이전 / 다음 이동 |
| 전체 구간 | 필터에 맞는 모든 기록 보기 |
| 최신 따라가기 | 확대 배율을 유지하며 새 기록 따라가기 |

직접 이동한 구간은 새 기록이 와도 유지됩니다. 전체 구간에서는 위치 슬라이더가 비활성화됩니다.

**기록 저장**은 현재 플래그·태그 필터와 확대 구간에 포함된 모든 기록을 저장합니다. 전체를 저장하려면 전체 메뉴에서 **모든 태그 → 전체 구간**을 선택하세요.

저장 위치: `config/feedback_flag/archives/`

- **게임에서 보기:** 메뉴의 **저장 기록**에서 선택합니다. 저장본은 읽기 전용입니다.
- **파일로 보기:** 저장 폴더의 `timeline.html`을 브라우저로 엽니다. 인터넷 없이 검색·확대·구간 이동·상세 확인이 가능합니다.
- **백업·이동:** `timeline.json`과 `timeline.html`이 들어 있는 폴더 전체를 복사합니다. 다른 게임 프로필에서는 `config/feedback_flag/archives` 아래에 넣고 **새로고침**하세요.

저장본은 원래 0틱 기준, 변화 당시 이름·색상, 저장 당시 태그·메모를 유지합니다. 현재 기록을 초기화해도 저장본은 남습니다.

## 표시와 초기화

**표시**에서 플래그 / 감시 블록 윤곽선 / 둘 다를 선택합니다. **표시 설정**에서 윤곽선 두께, 플래그 크기·위치, 이름 표시, 가려진 윤곽선과 전체 투명도를 조절합니다. 투명도 0%는 불투명, 100%는 보이지 않음이며 기록 여부와는 별개입니다. 플래그 위치 설정은 표시 위치만 옮깁니다.

- **전체 제거:** 확인 후 현재 월드/서버의 모든 차원에 있는 플래그와 메모를 제거합니다. 기존 타임라인은 유지합니다.
- **타임라인 초기화:** 확인 후 전체 기록과 누적 횟수를 지웁니다. 첫 새 변화가 다시 0틱이 됩니다. 특정 플래그 화면에서는 그 플래그만 초기화하며 공통 0틱 기준은 유지합니다. 태그 필터와 관계없이 버튼에 표시된 전체/개별 범위에 적용되며 **초기화는 되돌릴 수 없습니다.**

## 기록 범위와 보관

- 로딩된 블록의 종류·상태 변화만 기록합니다. 접속 종료·차원 이동·청크가 로딩되지 않은 동안의 변화와 상자 내용물·표지판 문구는 기록하지 않습니다.
- 시간은 클라이언트가 변화를 받은 시점의 게임틱 기준입니다. 네트워크 지연으로 서버의 실제 변경 시점과 차이가 날 수 있습니다.
- 월드/서버당 **128개 플래그**, 최근 **5,000개 기록**을 보관합니다. 오래된 기록이 자동 제거되어도 공통 0틱 기준은 유지됩니다.
- 데이터는 `config/feedback_flag/worlds/`에 저장됩니다. 월드 경로나 서버 주소가 바뀌면 별도 대상으로 인식합니다. 강제 종료 시 최근 저장 이후 기록이 유실될 수 있습니다.

## 개발 자료

Java 25에서 `./gradlew build`로 빌드합니다. Windows에서는 `gradlew.bat build`를 사용하세요. 설치 JAR는 `build/libs/`에 생성됩니다.
