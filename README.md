# Feedback Flag · 피드백 플래그

Minecraft Java **26.2 / Fabric**용 개인 블록 관찰 도구입니다. 블록 위에 색깔 있는 플래그를 꽂고, 여러 블록의 변화를 하나의 타임라인에서 확인할 수 있습니다. 서버 설치는 필요하지 않으며 다른 플레이어에게는 표시되지 않습니다.

## 설치

- Minecraft Java 26.2
- Fabric Loader 0.19.5 이상
- Minecraft 26.2용 Fabric API 0.160.0 이상
- Java 25 이상 (게임 런처에 포함된 Java 사용 가능)

`feedback-flag-0.1.4.jar`와 해당 버전의 Fabric API를 게임의 `mods` 폴더에 넣습니다. `-sources.jar`는 개발용 소스이며 설치 파일이 아닙니다. 업데이트할 때는 이전 Feedback Flag JAR를 새 버전으로 교체하세요.

## 사용 방법

1. 월드에 들어가 `/feedbackflag` 또는 `/ff`로 메뉴를 엽니다.
2. **플래그 꽂기**를 선택하고 감시할 블록을 우클릭합니다. 설치 모드에서는 블록의 원래 우클릭 동작이 실행되지 않습니다.
3. 플래그의 **이름(최대 32자)**, 색상, 태그와 메모를 정하고 **저장**합니다. 색상은 **기본 16색** 또는 `RRGGBB` 형식으로 지정할 수 있습니다. 마우스를 올리면 색상 이름과 RGB 값이 나옵니다.
4. 이후 플래그 자체를 우클릭하면 세부 설정이 열립니다. **빈손으로 웅크린 상태에서 대상 블록을 우클릭**해도 열 수 있습니다. 블록을 평소처럼 우클릭하면 레버 등 원래 기능이 작동합니다.
5. 메뉴 왼쪽에서 모든 플래그의 누적 작동 횟수와 상태를 확인합니다. 초록색은 감시 중, 노란색은 정지, 회색은 다른 차원 또는 로딩되지 않은 대상입니다.
6. 오른쪽 타임라인은 **첫 변화가 0틱인 상대 틱**을 사용합니다. 같은 틱의 변화는 한 행으로 묶이며, 여러 플래그가 있으면 **외 N개**를 표시합니다. 접힌 묶음에는 플래그 이름 대신 색상만 표시합니다. 점이나 묶음을 클릭하면 펼쳐지고, 안의 개별 변화를 클릭하면 상세 내용이 열립니다. 스크롤과 이동 버튼으로 긴 목록을 볼 수 있습니다.

설정 화면의 **이 플래그의 기록 보기**로 특정 플래그만 필터링할 수 있습니다. 플래그를 제거해도 기존 기록과 당시의 이름·색상은 보존됩니다.

### 플래그별 메모

플래그 세부 설정 오른쪽에 **메모 입력칸**이 항상 표시됩니다. 별도 창을 열지 않고 바로 읽고 수정할 수 있습니다. 이름과 별개로 저장되며 한글·줄바꿈을 포함해 최대 1,024자입니다. **저장**을 누르면 이름·색상 등 다른 설정과 함께 저장됩니다. **취소/Escape**는 저장하지 않은 설정과 메모를 모두 취소합니다. 창 크기를 바꿔도 작성 중인 내용은 유지됩니다.

메모는 이름을 변경하거나 블록 상태가 바뀌어도 유지되고, 게임을 다시 실행한 뒤에도 남습니다. 변화 상세 화면에는 **현재 플래그 메모**가 표시됩니다. 메모는 과거 기록마다 복사하지 않으며, 플래그를 제거하면 그 플래그의 메모도 제거됩니다. 월드 위에는 기존처럼 짧은 이름만 표시합니다. 0.1.0에서 저장한 플래그는 메모가 빈 상태로 정상적으로 불러옵니다.

### 사용자 지정 태그와 타임라인 필터

세부 설정의 **태그** 입력칸에 `입력, 회로 A`처럼 쉼표로 구분해 작성합니다. 플래그당 최대 8개, 태그당 최대 24자이며 앞뒤 공백과 중복 태그는 정리합니다. 영문 대소문자는 같은 태그로 취급합니다. **저장**을 누르면 적용되며 취소하면 원래 태그가 유지됩니다.

타임라인 위 **태그: 모든 태그** 버튼에서 태그를 선택하거나 검색합니다. **태그 없음**은 태그를 지정하지 않은 플래그만 보여줍니다. 선택한 플래그의 기록 화면에서도 태그 필터를 함께 사용할 수 있습니다. 태그를 바꾸면 해당 플래그의 기존 기록에도 새 태그 기준이 적용되며, 플래그를 제거하면 마지막 태그를 기존 기록에 보존합니다. 묶음을 펼치면 같은 플래그가 같은 틱에 여러 번 변한 기록도 각각 확인할 수 있습니다.

| 명령어 | 동작 |
| --- | --- |
| `/feedbackflag`, `/ff` | 전체 메뉴 열기 |
| `/feedbackflag add` | 현재 바라보는 블록에 즉시 추가하고 설정 열기 |
| `/feedbackflag place` | 다음 우클릭으로 꽂는 설치 모드 켜기/취소 |

## 설정

- **단축키:** 메뉴의 **단축키 설정**에서 **메뉴 열기**와 **플래그 꽂기**에 각각 키나 마우스 버튼을 지정합니다. 둘 다 기본 미지정이며, 각 행의 **해제** 또는 지정 대기 중 Escape로 해당 키만 비웁니다. 꽂기 키를 누른 뒤 블록을 우클릭하면 플래그 하나를 추가합니다. 같은 키를 다시 누르면 설치를 취소합니다. 화면에서 글을 입력하는 동안에는 단축키가 작동하지 않습니다. 중복 키 안내와 Minecraft 기본 키 지정 화면도 지원합니다.
- **플래그 전체 제거:** 왼쪽 플래그 목록의 **전체 제거**를 누르면 개수와 범위를 알리는 확인창이 열립니다. 확인하면 현재 월드/서버의 모든 차원에 있는 플래그와 메모를 제거합니다. 기존 타임라인과 마지막 태그, 상대 틱 기준, 표시 설정은 유지됩니다. 실제 블록은 변하지 않으며 제거 후에도 새 플래그를 꽂을 수 있습니다.
- **표시 방식:** 메뉴 왼쪽의 **표시** 버튼을 눌러 **플래그 → 블록 윤곽선 → 둘 다**로 전환합니다. 윤곽선은 WorldEdit CUI처럼 감시 좌표의 1블록 경계를 플래그 색으로 표시하며 가려진 부분도 확인할 수 있습니다. 공기 좌표가 되어도 같은 영역을 표시합니다. WorldEdit/CUI 설치는 필요하지 않습니다. 플래그가 숨겨져 있으면 메뉴 또는 빈손으로 웅크려 블록을 우클릭해 설정을 엽니다. 표시 선택은 현재 월드/서버에 저장됩니다.
- **표시 설정:** 위쪽 **표시 설정**에서 현재 월드/서버 전체의 표시 방식을 자세히 조절합니다. 수정한 값은 **저장**할 때 반영되며 **취소/Escape**는 버립니다. **표시 설정 기본값 복원**도 저장 전에는 작성 중인 설정에만 적용됩니다.

| 표시 항목 | 범위 / 동작 |
| --- | --- |
| 윤곽선 두께 | 기본 2, 1~8. 변화 직후 잠시 1.5배 두께로 강조 |
| 플래그 크기 | 기본 100%, 25~300%. 이름과 클릭 영역도 함께 조절 |
| 위치 X / Z | 기본 0, -2~+2블록. X+는 동쪽, Z+는 남쪽 |
| 높이 Y | 기본 0, -1~+3블록. 블록 위의 기본 플래그 위치에서 이동 |
| 전체 투명도 | 0~100%, 플래그와 윤곽선에 함께 적용 |
| 이름 표시 | 월드에 표시하는 플래그 이름 켜기/끄기 |
| 가려진 윤곽선 | 켜면 다른 블록 뒤에 가려진 윤곽선도 표시 |

플래그의 위치 변경은 표시만 움직입니다. **감시 대상 좌표와 블록 윤곽선은 이동하지 않습니다.** 기존 버전 저장 파일은 기존 크기·위치·두께에 맞는 기본값으로 불러옵니다.

- **타임라인 초기화:** 전체 메뉴에서 **타임라인 초기화**를 누르고 확인하면 현재 월드/서버의 모든 기록과 누적 작동 횟수가 지워집니다. 특정 플래그의 기록 화면에서는 **이 플래그 초기화**로 해당 플래그만 초기화합니다. 플래그·태그·메모·색상·활성화·표시 방식은 유지되며 다음 변화부터 새로 기록합니다. **전체 초기화 후 첫 변화가 새 0틱**이 됩니다. 개별 초기화는 공통 시간 기준을 바꾸지 않습니다. 태그 필터와 관계없이 버튼에 표시된 전체/개별 범위를 지우며 초기화는 되돌릴 수 없습니다.
- **전체 기록:** 현재 월드/서버의 모든 플래그 기록을 켜거나 끕니다. 개별 설정은 유지합니다.
- **이 플래그 기록:** 해당 플래그의 모든 기록을 켜거나 끄는 상위 스위치입니다. 꺼두면 아래 두 스위치가 켜져 있어도 기록하지 않습니다. 다시 켜도 꺼져 있던 동안의 변화를 소급 기록하지 않습니다. 정지된 표시는 흐려집니다.
- **전체 투명도:** 플래그와 블록 윤곽선에 함께 적용되며, 0%는 불투명, 100%는 보이지 않음입니다. 투명도는 기록 여부와 별개이며 현재 월드/서버에 적용됩니다.
- **블록:** 블록 종류가 달라지는 변화만 선택합니다. 예: 돌 → 공기(제거), 공기 → 레버(설치).
- **상태:** 같은 블록의 속성 변화만 선택합니다. 예: 레버의 전원 `powered`, 문의 열림 `open`, 작물 성장 `age`. 세 스위치에 마우스를 올리면 설명을 볼 수 있습니다.

한국어와 영어를 지원하며 게임 언어 설정을 따릅니다.

## 기록 범위와 보관

- 클라이언트가 **서버에서 받은 블록 상태 변경**을 기록합니다. 서버가 전송하지 않은 순간적인 중간 상태는 알 수 없습니다. 로컬 설치 예측은 확정 기록으로 취급하지 않습니다.
- 타임라인에 표시되는 시간은 **첫 기록 이후 경과한 게임틱**입니다. 최초 변화가 0틱이고, 이후 수신한 월드 게임틱과 최초 값의 차이를 표시합니다. 현실 시각이나 월드의 절대 틱 번호는 표시하지 않습니다. 태그 필터, 개별 플래그 보기, 재접속, 오래된 기록 자동 제거에도 원래 0틱 기준을 유지합니다. 전체 타임라인 초기화만 기준을 새로 잡습니다.
- 같은 틱은 한 묶음이며 **외 N개는 서로 다른 플래그 수에서 하나를 뺀 값**입니다. 묶음의 색상 하나는 플래그 하나입니다. 한 플래그가 같은 틱에 여러 번 변하면 색상은 한 번, 펼친 변화 목록은 각각 표시합니다.
- 0.1.2 저장 파일은 남아 있는 첫 기록을 기준으로 상대 틱을 계산합니다. 0.1.0/0.1.1 기록은 **이전 기록의 첫 변화**를 별도 기준으로 사용합니다. 서로 다른 시간 기준이 섞이거나 월드 시간이 되돌아간 페이지는 점을 수신 순서로 배치합니다. 시간을 되돌린 경우 상대 틱이 음수일 수 있습니다.
- 월드가 멈추면 게임틱도 멈춥니다. 클라이언트가 받은 시점의 월드 틱을 사용하므로 서버의 실제 변경 틱과 네트워크 지연만큼 차이가 날 수 있습니다.
- 로딩된 청크만 관찰합니다. 접속 종료, 차원 이동, 청크 언로드 기간의 변화를 추정해 채우지 않습니다. 감시 재개 시 현재 상태를 새 기준으로 삼습니다.
- 보관함 아이템, 표지판 문구 등 **블록 엔티티 데이터(NBT)는 기록하지 않습니다**. 이 버전은 블록 종류와 상태값을 감시합니다.
- 월드/서버당 최대 **128개 플래그**, 최근 **5,000개 기록**을 보관합니다. 보관 상한으로 오래된 기록이 자동 제거되어도 누적 작동 횟수는 유지됩니다. 수동 초기화는 해당 누적 횟수도 0으로 되돌립니다.
- 플래그는 96블록 거리까지 표시되며 F1로 HUD를 숨기면 함께 숨겨집니다. 대상 블록이 없어져도 해당 좌표를 계속 감시합니다.
- 데이터는 `config/feedback_flag/worlds/<식별자 해시>.json`에 저장됩니다. 싱글 월드 경로와 서버 주소별로 구분하고 차원·좌표도 별도로 관리합니다. 월드 폴더나 서버 주소가 바뀌면 새 대상으로 인식합니다.
- 설정 변경 및 접속 종료 때 저장하며, 기록은 5초마다 저장합니다. 강제 종료 시 마지막 저장 이후 기록은 유실될 수 있습니다. 파일은 임시 파일을 완성한 뒤 교체합니다. 불러오기에 실패하면 원본을 덮어쓰지 않고 메뉴에 오류를 표시합니다.

## 개발과 검증

Java 25와 Gradle Wrapper 9.5.1을 사용합니다. Minecraft 26.2는 공식 비난독화 이름을 사용합니다.

```sh
./gradlew build
./gradlew runClientGameTest
```

Windows에서는 `gradlew.bat`를 사용합니다. `build`는 모드 생성과 123개 모델 검증 항목을 실행합니다. `runClientGameTest`는 별도 테스트 월드에서 실제 패킷, 클릭, 설정, 단축키, 화면 내 메모 입력·저장·취소, 상대 틱 기준·게임틱 정지, 태그 필터, 틱 묶음 접기·펼치기, 표시 방식·크기·위치와 클릭 영역, 전체 제거 확인/취소, 초기화와 화면 출력을 확인합니다. 테스트 전용 코드는 설치용 JAR에 포함되지 않습니다. 생성물은 `build/libs`, 게임 테스트 스크린샷은 `build/run/clientGameTest/screenshots`에 있습니다.

GitHub Actions는 빌드 결과를 `feedback-flag` 아티팩트로 보관합니다.

개발 API 참고: [Fabric 26.2](https://fabricmc.net/2026/06/15/262.html), [Fabric 게임 테스트](https://docs.fabricmc.net/develop/automatic-testing).
